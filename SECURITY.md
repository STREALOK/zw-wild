# Security

zw-wild, as listed in the directory, is text files and one icon: no hooks, no connectors, no server. Its pages and widgets run in the viewer's own browser, and its optional Python tool runs only when the person asks for it, through Claude's normal permission prompts.

## Reporting a problem

- If the repository's Security tab (https://github.com/STREALOK/zw-wild/security) offers «Report a vulnerability», please use it for anything that should stay private until it is fixed.
- Otherwise open an issue at https://github.com/STREALOK/zw-wild/issues. Leave the details out of the public issue, say that you have a security report, and we will arrange a private way to receive it.

Every report is read and answered as soon as we can.
